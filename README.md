# 柏宝绘 · 漫画分镜版

基于 [ST-BaiBai-Image](https://github.com/baibai-git/ST-BaiBai-Image) 0.3.2 修改的完整 SillyTavern 扩展，当前版本 **0.3.3**。完整源码和编译后的 `dist` 已包含，可直接安装，无需粘贴预设或手工应用补丁。原项目作者：柏柏。

## 安装地址

在酒馆「扩展 → 安装扩展」中填写：

```text
https://github.com/stilljy-commits/manhua.git
```

已安装原版柏宝绘的，先停用原版并刷新，再安装本版，不要同时启用两份。本版沿用原版设置与角色库的存储键，可读取现有渠道和角色库。建议切换前备份酒馆用户数据，保留原版安装以便回退。

初次从原版切换需要安装本仓库，原版更新按钮不能切换仓库来源；本版后续的更新按钮指向本仓库。

## 漫画模式开关

在「设置 → 自动生成 tag」中切换 **漫画分镜配图（NAI）**：

- **开**：使用内置漫画规划，把一个事件画成一张 2～3 格插图；静态片段可用单格。自动启用英文页面描述，继续维护角色建档和永久变化，默认无上画文字。
- **关**：恢复原版单图流程及已有自定义 NAI 规范、思维链；自然语言开关也恢复按原配置执行。

模式默认开启，可随时关闭；切换不删除原有提示词、渠道、角色库或图片。已有图片需要重新生成 tag 才会使用新模式。ComfyUI 沿用原流程。

仅漫画页的 NAI 请求移除负面词中与分格冲突的 `multiple views`、`halftone`、`screentone`，不改写保存的负面词设置。

## 验证

类型检查和生产构建通过。59 个测试文件通过：781 项通过，3 项跳过。检查包含模式开关回退、旧自定义提示词兼容、角色建档、页面描述发送和负面词处理。

尚未在用户酒馆实例运行或实际出图，不保证精确格数与跨格人物一致性。`examples/` 是提示词样例；`presets/`、`patches/` 是前期参考资料，直接安装本版不需要使用它们。

## 源码构建

使用 Node.js 22.12+ 或 24，运行 `pnpm install`、`pnpm typecheck`、`pnpm test`、`pnpm build`。普通酒馆用户无需构建。
